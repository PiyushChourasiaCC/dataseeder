## 1. Database/Object Model (DB-LAYER)

### Salesforce Data Model Considerations
- Custom Objects have a __c suffix (e.g., DataSeederTemplate__c)
- Custom Fields have a __c suffix (e.g., Description__c)
- System fields like Id, CreatedById are automatically provided
- Relationship fields end with __r for the relationship and __c for the ID field
- Salesforce enforces Field-Level Security and Object-Level Security
- Standard Objects (Account, Contact, etc.) have their own field limits
- Metadata deployment must include both object and field definitions

## 2. Permissions (PERM-LAYER)

### Salesforce Security Model
- Profiles control baseline object and field access
- Permission Sets provide additive permissions beyond profiles
- Field-Level Security controls visibility and editability of fields
- Object-Level Security controls Create/Read/Edit/Delete permissions
- Apex classes require explicit permissions for non-admin users
- Organization-Wide Defaults (OWDs) set baseline sharing model
- Sharing Rules can extend access beyond OWDs
- Record-Level security enforced via ownership and sharing

## Salesforce Glossary for AI Agent Reference

**Apex**: Salesforce's proprietary programming language with Java-like syntax used for backend development.

**API Version**: Salesforce releases three major versions yearly. Each component must specify which API version it uses.

**Custom Object**: Salesforce data table that stores information specific to an organization's process.

**DML (Data Manipulation Language)**: Operations used to insert, update, delete, or upsert Salesforce records.

**Governor Limits**: Runtime limits enforced by Salesforce to ensure multi-tenant architecture stability.

**LWC (Lightning Web Components)**: Salesforce's UI development framework using modern web standards.

**Permission Set**: Collection of settings and permissions that give users access to tools and functions.

**SFDX (Salesforce Developer Experience)**: Modern development tools and workflows for Salesforce development.

**SLDS (Salesforce Lightning Design System)**: CSS framework providing design patterns and components.

**SOQL (Salesforce Object Query Language)**: Database query language similar to SQL but optimized for Salesforce data.

**SObject**: Salesforce's representation of database objects/records in Apex.

**Bulkification**: Pattern of processing records in batches rather than individually to avoid governor limits.
